## API reference

Use these APIs to fetch configured Setu Insights outputs after a Signal IQ flow completes successfully. Every successful terminal webhook carries a `reportId` - pass that id to the endpoint for the format you need.

<br />

| Output | Method | Endpoint |
|--------|--------|----------|
| Setu Insights JSON | `GET` | `/v1/insights/&#123;reportId&#125;` |
| Setu Insights Excel | `GET` | `/v1/insights/excel/&#123;reportId&#125;` |
| Setu Insights XML | `GET` | `/v1/insights/xml/&#123;reportId&#125;` |

<br />

<Callout type="note">
  Webhooks deliver status notifications (including `reportId` on success). Fetch the report body with these APIs. If you want results in the `INSIGHTS_CREATION_SUCCESSFUL` webhook, that can be customised during onboarding - see the <a href="/data/signal-iq/overview#the-experience-is-the-same-across-every-flow" target="_blank">Overview</a>.
</Callout>
