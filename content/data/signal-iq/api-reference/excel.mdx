## Setu Insights in Excel

Fetch the Setu Insights report for a completed Signal IQ run as Excel.

`GET /v1/insights/excel/{reportId}`

<br />

<Callout type="tip">
  The indicators included in this Excel output are configured per client during onboarding. The success body below is a sample - your file may include a different set of indicators and sheets.
</Callout>

<hr class="primary" />

### Authentication

Send the same client credentials style used by Setu Insights.

| Header | Required | Description |
|--------|----------|-------------|
| `x-client-id` | Yes | Your client id |
| `x-client-secret` | Yes | Your client secret |
| `x-product-instance-id` | No | Your product instance id, if issued to you |
| `authorization` | No | Bearer token, if your integration uses JWT/OAuth |

<br />

### Path parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `reportId` | UUID string | Yes | The `reportId` from the terminal success webhook |

<hr class="primary" />
